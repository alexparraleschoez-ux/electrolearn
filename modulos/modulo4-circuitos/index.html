Teoría: Tipos de Circuitos

Circuito en Serie

En un circuito en serie, los componentes están conectados uno después del otro, formando un solo camino para la corriente.

📏 Características:

  • ✓ Una sola ruta para la corriente
  • ✓ La corriente es igual en todos los componentes
  • ✓ El voltaje se divide entre los componentes
  • ✓ Si un componente falla, todo se detiene

📐 Fórmulas:

Rt = R1 + R2 + R3 + ...

Resistencia total = suma de todas

It = I1 = I2 = I3 = ...

Corriente igual en todos

Vt = V1 + V2 + V3 + ...

Voltaje total = suma de voltajes

💡 Ejemplo real: Luces navideñas antiguas. Si una se quema, todas se apagan.

Circuito en Paralelo

En un circuito en paralelo, los componentes están conectados en ramas separadas, formando múltiples caminos para la corriente.

Características:

  • ✓ Múltiples rutas para la corriente
  • ✓ El voltaje es igual en todas las ramas
  • ✓ La corriente se divide entre las ramas
  • ✓ Si una rama falla, las demás siguen

📐 Fórmulas:

1/Rt = 1/R1 + 1/R2 + 1/R3 + ...

Resistencia total (inversa)

Vt = V1 = V2 = V3 = ...

Voltaje igual en todas las ramas

It = I1 + I2 + I3 + ...

Corriente total = suma de corrientes

💡 Ejemplo real: Instalación eléctrica de tu casa. Si se funde un foco, los demás siguen funcionando.

Circuito Mixto

Un circuito mixto combina conexiones en serie y paralelo en el mismo circuito. Es el más común en aplicaciones reales.

Método de resolución:

  1. Identifica las partes en serie y paralelo
  2. Calcula primero las resistencias en paralelo
  3. Sustituye por su resistencia equivalente
  4. Calcula las resistencias en serie restantes
  5. Obtén la resistencia total

💡 Ejemplo real: Circuitos de computadoras, televisores, automóviles.

Comparación: Serie vs Paralelo

Característica Serie Paralelo
Rutas de corriente Una sola Múltiples
Corriente Igual en todos Se divide
Voltaje Se divide Igual en todos
Resistencia total Mayor que la mayor Menor que la menor
Si falla un componente Todo se detiene Los demás siguen
Ejemplo Luces navideñas Casa eléctrica
