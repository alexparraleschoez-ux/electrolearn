¿Qué es un Laboratorio Virtual?

Un laboratorio virtual permite experimentar con circuitos electrónicos de forma segura, sin necesidad de componentes físicos. Es ideal para aprender y practicar.

✅ Ventajas:

  • ✓ Sin riesgo de quemar componentes
  • ✓ Disponible 24/7
  • ✓ Gratis
  • ✓ Fácil de compartir

🎯 Usos:

  • ✓ Practicar antes de armar
  • ✓ Probar ideas rápidamente
  • ✓ Aprender conceptos
  • ✓ Tareas y proyectos

🔧 Herramientas:

  • ✓ PhET Simulations
  • ✓ Tinkercad Circuits
  • ✓ Falstad Circuit
  • ✓ EveryCircuit

Tinkercad Circuits

Tinkercad de Autodesk permite simular circuitos con Arduino, componentes reales y código.

🎯 Características:

  • Componentes reales (resistencias, LEDs, sensores)
  • Arduino Uno programable
  • Código en bloques o texto (C++)
  • Simulación en tiempo real
  • Multímetro virtual integrado
  • Serial monitor
  • Guardar y compartir proyectos
  • Gratis con cuenta de Autodesk

Falstad Circuit Simulator

Falstad es un simulador de circuitos avanzado y gratuito, ideal para electrónica analógica.

🔬 Características avanzadas:

  • Componentes: R, L, C, diodos, transistores, op-amps
  • Osciloscopio integrado
  • Visualización de corriente en tiempo real
  • Análisis de frecuencia (Bode)
  • Circuitos digitales y analógicos

🎓 Ideal para:

  • Estudiantes de electrónica
  • Filtros activos y pasivos
  • Amplificadores operacionales
  • Osciladores y temporizadores
  • Fuentes de poder

Guía: Cómo Usar los Simuladores

1️⃣ PhET - Para principiantes

  1. Abre el enlace del simulador
  2. Arrastra componentes desde el panel lateral
  3. Conéctalos haciendo clic en los terminales
  4. Usa el multímetro para medir
  5. Experimenta cambiando valores

2️⃣ Tinkercad - Para Arduino

  1. Crea cuenta gratuita en tinkercad.com
  2. Ve a "Circuits" → "Create new Circuit"
  3. Arrastra Arduino y componentes
  4. Conecta con cables (clic en pin, luego en destino)
  5. Escribe código en "Code" (bloques o texto)
  6. Click "Start Simulation" para probar

3️⃣ Falstad - Para avanzado

  1. Abre falstad.com/circuit
  2. Usa el menú "Draw" para agregar componentes
  3. Clic derecho para editar valores
  4. Usa "Scope" para ver formas de onda
  5. Explora ejemplos en "File" → "Examples"
