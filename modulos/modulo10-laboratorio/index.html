¿Qué es un Laboratorio Virtual?

Un laboratorio virtual permite experimentar con circuitos electrónicos de forma segura, sin necesidad de componentes físicos.

  • ✓ Fácil de compartir

🎯 Usos:

  • ✓ Practicar antes de armar

Guía: Cómo Usar los Simuladores

1️⃣ PhET - Para principiantes

  1. Abre el enlace del simulador
  2. Arrastra componentes desde el panel lateral
  3. Conéctalos haciendo clic en los terminales
  4. Usa el multímetro para medir
  5. Experimenta cambiando valores

2️⃣ Tinkercad - Para Arduino

  1. Crea cuenta gratuita en tinkercad.com
  2. Ve a "Circuits" → "Create new Circuit"
  3. Arrastra Arduino y componentes
  4. Conecta con cables (clic en pin, luego en destino)
  5. Escribe código en "Code" (bloques o texto)
  6. Click "Start Simulation" para probar

3️ Falstad - Para avanzado

  1. Abre falstad.com/circuit
  2. Usa el menú "Draw" para agregar componentes
  3. Clic derecho para editar valores
  4. Usa "Scope" para ver formas de onda
  5. Explora ejemplos en "File" → "Examples"
