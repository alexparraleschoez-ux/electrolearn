Teoría: Componentes Electrónicos Básicos

Resistencias

Las resistencias son componentes que limitan el flujo de corriente en un circuito. Son los componentes más comunes en electrónica.

📏 Características:

  • ✓ Se miden en Ohmios (Ω)
  • ✓ Tienen bandas de colores
  • ✓ Disipan energía en forma de calor
  • ✓ No tienen polaridad

🎯 Usos comunes:

  • ✓ Limitar corriente en LEDs
  • ✓ Divisores de voltaje
  • ✓ Pull-up y pull-down
  • ✓ Filtros de señal

💡 Dato importante: El valor de una resistencia se lee mediante el código de colores de sus bandas.

Capacitores (Condensadores)

Los capacitores son componentes que almacenan energía eléctrica en un campo eléctrico. Funcionan como baterías temporales de carga rápida.

📏 Características:

  • ✓ Se miden en Faradios (F)
  • ✓ Común: μF, nF, pF
  • ✓ Algunos tienen polaridad (+/-)
  • ✓ Se cargan y descargan

🎯 Usos comunes:

  • ✓ Filtrar ruido en circuitos
  • ✓ Almacenar energía temporal
  • ✓ Acoplar señales AC
  • ✓ Temporizadores

💡 Tipos: Cerámicos (sin polaridad), Electrolíticos (con polaridad), Tantalio, Poliéster.

Diodos

Los diodos son componentes que permiten el flujo de corriente en una sola dirección. Actúan como válvulas unidireccionales.

📏 Características:

  • ✓ Tienen polaridad (Ánodo/Cátodo)
  • ✓ Caída de voltaje: ~0.7V (Silicio)
  • ✓ Conducen en polarización directa
  • ✓ Bloquean en polarización inversa

Usos comunes:

  • ✓ Rectificación (CA a CC)
  • ✓ Protección de circuitos
  • ✓ Diodo Zener (regulación)
  • ✓ Diodo LED (emite luz)

⚠️ Polaridad: La pata larga es el Ánodo (+), la pata corta es el Cátodo (-).

LEDs (Diodos Emisores de Luz)

Los LEDs son diodos especiales que emiten luz cuando circula corriente en polarización directa.

📏 Características:

  • ✓ Requieren resistencia limitadora
  • ✓ Corriente típica: 20-30 mA
  • ✓ Voltaje según color (1.8V-3.3V)
  • ✓ Muy eficientes energéticamente

Colores y voltajes:

  • 🔴 Rojo: ~1.8V-2.2V
  • 🟢 Verde: ~2.0V-2.4V
  • 🔵 Azul: ~3.0V-3.4V
  • Blanco: ~3.0V-3.4V

⚠️ IMPORTANTE: Siempre usa una resistencia en serie con un LED para limitar la corriente y evitar que se queme.

Transistores

Los transistores son componentes semiconductores que pueden amplificar señales o actuar como interruptores electrónicos.

📏 Tipos principales:

  • ✓ NPN: Más común
  • ✓ PNP: Complementario
  • ✓ MOSFET: Alta eficiencia
  • ✓ 3 terminales: Base, Colector, Emisor

🎯 Usos comunes:

  • ✓ Amplificación de señales
  • ✓ Interruptores electrónicos
  • ✓ Control de motores
  • ✓ Circuitos lógicos

💡 Funcionamiento: Una pequeña corriente en la Base controla una corriente mayor entre Colector y Emisor.
