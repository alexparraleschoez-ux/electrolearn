Teoría: Componentes Avanzados

Capacitores en Profundidad

Los capacitores almacenan energía en un campo eléctrico. Su capacidad se mide en Faradios (F).

📏 Tipos principales:

  • ✓ Cerámicos: Pequeños, sin polaridad (pF-nF)
  • ✓ Electrolíticos: Grandes, con polaridad (μF-mF)
  • ✓ Tantalio: Estables, polarizados
  • ✓ Poliéster: Precisión, audio

Fórmulas importantes:

Q = C × V

Carga = Capacitancia × Voltaje

E = ½ × C × V²

Energía almacenada

τ = R × C

Constante de tiempo

💡 Constante de tiempo (τ): Tiempo que tarda un capacitor en cargarse al 63.2% de su valor máximo. Después de 5τ está completamente cargado (99.3%).

Diodos Especiales

Además del diodo rectificador estándar, existen tipos especializados para diferentes aplicaciones.

🔴 Diodo Zener:

  • ✓ Regula voltaje en polarización inversa
  • ✓ Voltajes: 2.4V a 200V
  • ✓ Usos: Reguladores, protección
  • ✓ Símbolo: Diodo con línea en Z

💡 LED (Diodo Emisor de Luz):

  • ✓ Emite luz en polarización directa
  • ✓ Voltaje: 1.8V-3.4V según color
  • ✓ Corriente: 20-30 mA típico
  • ✓ Requiere resistencia limitadora

Diodo Schottky:

  • ✓ Caída de voltaje baja: 0.2-0.3V
  • ✓ Conmutación rápida
  • ✓ Usos: Fuentes switching, RF
  • ✓ Menor pérdida de energía

📡 Fotodiodo:

  • ✓ Detecta luz (sensor óptico)
  • ✓ Opera en polarización inversa
  • ✓ Usos: Sensores, comunicaciones
  • ✓ Respuesta rápida a la luz

Transistores

Los transistores son semiconductores que amplifican señales o actúan como interruptores. Son la base de la electrónica moderna.

🔺 BJT (Bipolar Junction Transistor):

  • ✓ NPN: Más común (2N2222, BC547)
  • ✓ PNP: Complementario (2N2907, BC557)
  • ✓ 3 terminales: Base (B), Colector (C), Emisor (E)
  • ✓ Controlado por corriente de base
  • ✓ Ganancia: β (hFE) = 100-300 típico

⚡ MOSFET:

  • ✓ N-Channel: IRF520, 2N7000
  • ✓ P-Channel: IRF9520
  • ✓ 3 terminales: Gate (G), Drain (D), Source (S)
  • ✓ Controlado por voltaje de gate
  • ✓ Alta impedancia de entrada

💡 Aplicaciones: Amplificadores de audio, interruptores electrónicos, control de motores, fuentes de poder, circuitos lógicos.

Circuitos Integrados (IC)

Los circuitos integrados contienen múltiples componentes en un solo chip. Son la base de la electrónica moderna.

⏱️ Timer 555:

  • ✓ Genera pulsos y oscilaciones
  • ✓ Modos: Monoestable, Astable
  • ✓ Frecuencia: f = 1.44/((R1+2R2)×C)
  • ✓ Usos: Timers, PWM, osciladores

Op-Amp (741):

  • ✓ Amplificador operacional
  • ✓ Alta ganancia (100,000x)
  • ✓ Comparadores, filtros, amplificadores
  • ✓ Realimentación negativa

⚡ Regulador 7805:

  • ✓ Regula voltaje a 5V fijos
  • ✓ Entrada: 7V-35V
  • ✓ Corriente: hasta 1A
  • ✓ Protección térmica

💡 Importante: Los IC tienen una muesca o punto que indica el pin 1. Siempre verifica el datasheet antes de conectar.
