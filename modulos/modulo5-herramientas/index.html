Herramientas Esenciales

Cautín/Soldador

Herramienta para unir componentes mediante soldadura de estaño. Temperatura típica: 300-400°C.

Protoboard

Tablero de pruebas para armar circuitos sin soldar. Los agujeros están conectados internamente.

Pinzas de corte

Para cortar cables y patillas de componentes. Esenciales para trabajos de precisión.

Lupa

Para inspeccionar soldaduras y componentes pequeños. Muy útil en trabajos SMD.

Extractor de estaño

Para remover soldadura excedente o corregir errores. Funciona como una jeringa de succión.

Fuente de poder

Suministra voltaje regulable para probar circuitos. Más segura que usar baterías sueltas.

Normas de Seguridad

SÍ hacer:

  • Usar gafas de protección al soldar
  • Trabajar en área ventilada
  • Desconectar energía antes de medir
  • Verificar polaridad antes de conectar
  • Usar guantes térmicos con el soldador

NO hacer:

  • Tocar componentes calientes
  • Medir resistencia con circuito energizado
  • Usar herramientas dañadas
  • Dejar el soldador encendido sin supervisión
  • Trabajar con las manos mojadas
