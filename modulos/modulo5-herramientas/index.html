Multímetro, soldador, protoboard y herramientas esenciales

Teoría: Herramientas Esenciales

Multímetro Digital

El multímetro es la herramienta más importante en electrónica. Permite medir voltaje, corriente y resistencia en un solo dispositivo.

📏 Modos de medición:

  • ✓ Voltaje DC (V⎓): Baterías, circuitos DC
  • ✓ Voltaje AC (V~): Electricidad doméstica
  • ✓ Resistencia (Ω): Resistencias, continuidad
  • ✓ Corriente (A): Consumo de circuitos
  • ✓ Continuidad (🔊): Verificar conexiones

Partes del multímetro:

  • ✓ Display LCD: Muestra la medición
  • ✓ Selector: Elige el modo y rango
  • ✓ Terminal COM: Sonda negra (común)
  • ✓ Terminal VΩmA: Sonda roja (medición)
  • ✓ Terminal 10A: Corrientes altas

⚠️ Seguridad: Siempre conecta la sonda negra en COM y la roja en el terminal correcto. Nunca midas resistencia en un circuito energizado.

Protoboard (Breadboard)

El protoboard es una placa para construir circuitos sin soldar. Permite probar circuitos rápidamente.

📏 Estructura:

  • ✓ Rieles de alimentación (rojo/azul): Laterales
  • ✓ Área central: Filas de 5 puntos conectados
  • ✓ Canal central: Separa los dos lados
  • ✓ Pasos de 2.54mm: Estándar para componentes

🎯 Cómo usar:

  • ✓ Inserta componentes en los agujeros
  • ✓ Conecta con cables jumper
  • ✓ Los puntos en la misma fila están conectados
  • ✓ Los rieles laterales son para VCC y GND

💡 Tip: Usa cables de colores: rojo para positivo, negro para negativo/GND.

Soldador (Cautín)

El soldador une componentes metálicos usando estaño fundido. Es esencial para circuitos permanentes.

🌡️ Temperaturas:

  • ✓ 300-350°C: Soldadura estándar
  • ✓ 350-400°C: Componentes grandes
  • ✓ 250-300°C: Componentes SMD delicados

⚠️ Seguridad:

  • ✓ Usa gafas de protección
  • ✓ Trabaja en área ventilada
  • ✓ Nunca toques la punta
  • ✓ Desconecta cuando no uses

⚠️ Importante: Usa flux para mejores soldaduras y limpia la punta con esponja húmeda regularmente.

Otras Herramientas Esenciales

✂️ Pinzas de Corte

Cortan alambres y patillas de componentes con precisión.

🔧 Destornilladores

Planos y de cruz para ajustar tornillos de componentes.

Lupa

Inspeccionar soldaduras y componentes pequeños (SMD).

🧲 Extractor de Estaño

Elimina exceso de estaño en soldaduras defectuosas.

📏 Regla/Calibrador

Medir distancias entre pines y componentes.

🔦 Fuente de Poder

Alimenta circuitos con voltaje regulable (3.3V, 5V, 12V).

Normas de Seguridad

✅ SÍ HACER:

  • ✓ Usar gafas de protección al soldar
  • ✓ Trabajar en área ventilada
  • ✓ Desconectar energía antes de medir
  • ✓ Verificar polaridad antes de conectar
  • ✓ Usar guantes térmicos con el soldador
  • ✓ Mantener el área de trabajo ordenada

❌ NO HACER:

  • ✗ Tocar componentes calientes
  • Medir resistencia con circuito energizado
  • ✗ Usar herramientas dañadas
  • ✗ Dejar el soldador encendido sin supervisión
  • ✗ Trabajar con las manos mojadas
  • Sobrecargar los circuitos
