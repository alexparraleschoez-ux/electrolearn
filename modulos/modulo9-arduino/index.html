Teoría: Arduino

¿Qué es Arduino?

Arduino es una plataforma de hardware y software libre para crear proyectos electrónicos interactivos.

🔧 Hardware:

  • ✓ Microcontrolador ATmega328P
  • ✓ 14 pines digitales (0-13)
  • ✓ 6 pines analógicos (A0-A5)
  • ✓ Voltaje: 5V (3.3V en algunos)
  • ✓ Corriente por pin: 20-40mA

💻 Software:

  • ✓ Arduino IDE (gratis)
  • ✓ Lenguaje: C/C++ simplificado
  • ✓ Funciones: setup() y loop()
  • ✓ Librerías para sensores
  • ✓ Código abierto

Estructura del Código

void

setup

() {

// Se ejecuta UNA vez al inicio

pinMode(13, OUTPUT);

void

loop

() {

// Se ejecuta INFINITAMENTE

digitalWrite(13, HIGH);

digitalWrite(13, LOW);

delay(1000);

}

Tipos de Pines

🟢 DIGITALES:

  • ✓ HIGH (5V) o LOW (0V)
  • ✓ pinMode(pin, OUTPUT)
  • ✓ digitalWrite(pin, valor)
  • ✓ digitalRead(pin)

ANALÓGICOS:

  • ✓ 0-1023 (10 bits)
  • ✓ analogRead(pin)
  • ✓ Solo entrada
  • ✓ A0-A5

PWM (~):

  • ✓ 0-255 (8 bits)
  • ✓ analogWrite(pin, valor)
  • ✓ Pines: 3,5,6,9,10,11
  • ✓ Simula salida analógica

Funciones Principales

pinMode(pin, modo)

Configura pin como INPUT o OUTPUT

digitalWrite(pin, valor)

Escribe HIGH o LOW en pin digital

digitalRead(pin)

Lee valor de pin digital

analogRead(pin)

Lee valor analógico (0-1023)

analogWrite(pin, valor)

Escribe PWM (0-255)

delay(ms)

Espera milisegundos

Serial.begin(9600)

Inicia comunicación serial

Serial.println(texto)

Imprime en monitor serial
