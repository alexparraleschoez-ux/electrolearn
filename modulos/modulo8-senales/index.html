Teoría: Señales y Ondas

¿Qué es una Señal?

Una señal es una variación de voltaje o corriente que transporta información.

Señal Analógica:

  • ✓ Valores continuos
  • ✓ Infinitos valores posibles
  • ✓ Ejemplo: audio, temperatura
  • ✓ Susceptible al ruido

💻 Señal Digital:

  • ✓ Valores discretos (0 o 1)
  • ✓ Dos niveles: HIGH/LOW
  • ✓ Ejemplo: datos, lógica
  • ✓ Resistente al ruido

Características de una Onda

📏 Parámetros:

  • ✓ Amplitud (A): Valor máximo (V)
  • ✓ Frecuencia (f): Ciclos por segundo (Hz)
  • ✓ Período (T): Tiempo de un ciclo (s)
  • ✓ Fase (φ): Desplazamiento (°)

📐 Fórmulas:

f = 1/T

Frecuencia = 1/Período

T = 1/f

Período = 1/Frecuencia

Vrms = Vp/√2

PWM (Pulse Width Modulation)

El PWM varía el ancho del pulso para controlar potencia promedio.

Duty Cycle = (Ton/T) × 100%

Donde Ton = tiempo encendido, T = período total

Comunicación Serial

UART:

  • ✓ Asíncrona
  • ✓ TX, RX, GND
  • ✓ Velocidad: baudios
  • ✓ Ejemplo: Arduino Serial

I2C:

  • ✓ Sincrónica
  • ✓ SDA, SCL
  • ✓ Múltiples dispositivos
  • ✓ Ejemplo: sensores

SPI:

  • ✓ Sincrónica
  • ✓ MOSI, MISO, SCK, SS
  • ✓ Alta velocidad
  • ✓ Ejemplo: SD, displays

Señales de Radio

📻 AM (Amplitud Modulada):

Varía la amplitud. Largo alcance, susceptible al ruido.

📻 FM (Frecuencia Modulada):

Varía la frecuencia. Mejor calidad, menor alcance.
