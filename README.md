## 📖 Descripción

**ElectroLearn** es un repositorio digital interactivo diseñado para fortalecer el aprendizaje de **electricidad y electrónica básica**, dirigido a estudiantes de primer año de **Soporte Informático**.

Este proyecto transforma el aprendizaje tradicional en una experiencia interactiva, visual y práctica, permitiendo a los estudiantes experimentar con simuladores, calculadoras y contenido multimedia desde cualquier dispositivo.

##  Características Principales

### 🎯 5 Módulos Interactivos

1. ** Corriente Eléctrica**
   - Animaciones del flujo de electrones
   - Explicación de Corriente Continua (CC) y Alterna (CA)
   - Quiz interactivo con retroalimentación inmediata

2. **🔋 Ley de Ohm**
   - Simulador interactivo con sliders en tiempo real
   - Gráficos dinámicos con Chart.js
   - Interpretación automática de resultados
   - Ejercicios prácticos con pistas

3. **🔌 Componentes Electrónicos**
   - Calculadora de código de colores de resistencias
   - Visualización interactiva de bandas de color
   - Cálculo automático de tolerancia
   - Tabla de referencia completa

4. **🔗 Circuitos Eléctricos**
   - Calculadora de resistencia en serie
   - Calculadora de resistencia en paralelo
   - Diagramas visuales de circuitos
   - Explicación de circuitos mixtos

5. **🛠️ Herramientas de Medición**
   - Multímetro virtual interactivo
   - Simulador de protoboard
   - Galería de herramientas esenciales
   - Normas de seguridad
